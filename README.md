# 🍽️ Bar Restaurant Acuari - Página Web

## 📋 Contenido

Esta carpeta contiene la página web completa del **Bar Restaurant Acuari** de Cambrils, Tarragona.

### Archivos incluidos:

1. **index.html** - Página de inicio con:
   - Presentación del restaurante
   - Sección "Nuestra Cocina"
   - Horario de apertura
   - Experiencias (Cocina Mediterránea, Tapas, Ambiente, Terraza)
   - Vista previa del menú
   - Ubicación y contacto con mapa integrado

2. **menu.html** - Página del menú del día con:
   - Primeros platos
   - Segundos platos
   - Postres
   - Bebidas y otros
   - Contacto directo

3. **README.md** - Este archivo con instrucciones

## 🚀 Cómo usar

### Opción 1: Abrir localmente
1. Descarga los archivos (index.html y menu.html)
2. Abre `index.html` en tu navegador web
3. Navega entre páginas usando los enlaces

### Opción 2: Subir a un servidor web
1. Sube los archivos HTML a tu servidor web
2. Asegúrate de mantener ambos archivos en la misma carpeta
3. Los enlaces funcionarán correctamente

## 🎨 Características de diseño

- **Sistema de diseño**: Mediterranean Coastal Professional
- **Tipografía**:
