# 🍽️ Bar Restaurant Acuari

Página web profesional para Bar Restaurant Acuari - Gastronomía Mediterránea en Cambrils, Tarragona.

## 🚀 Usar Localmente

```bash
# Opción 1: Abrir directamente
Abre index.html en tu navegador

# Opción 2: Si tienes Python 3
python -m http.server 8000
# Luego abre: http://localhost:8000
```

## 📱 Desplegar en GitHub Pages

1. Crea un repositorio público en GitHub
2. Sube estos archivos
3. Ve a **Settings → Pages**
4. Selecciona **Deploy from a branch → main**
5. Elige carpeta **/ (root)**
6. ¡Listo! Tu sitio estará en `https://tu-usuario.github.io/acuari-web`

## 🔗 Publicar en Otros Servicios

**Vercel:**
```bash
npm i -g vercel
vercel
```

**Netlify:** Arrastra la carpeta a [netlify.com/drop](https://netlify.com/drop)
